# 棉花种植行有限线段人工标注工具

## 启动

在项目目录执行：

```powershell
$env:PYTHONUTF8 = "1"
python annotate_server.py
```

浏览器打开 `http://127.0.0.1:8765`。服务默认只监听本机地址，原始航片不会上传到外部平台。

## 标注操作

1. 左侧选择图像；首次启动自动打开第一张。
2. 保持“画线”模式，按住鼠标左键，从一条可见种植行的一端拖到另一端。
3. 每个物理种植行只画一条中心线。缺苗但行结构明确时仍画成一条连续有限线。
4. 切换到“选择”后单击线段，使用 `Delete` 删除。
5. `Ctrl+Z` 撤销，`Ctrl+S` 保存，`A/D` 切换上一张/下一张，`F` 适应窗口。
6. 鼠标滚轮缩放；右键拖动或按住空格拖动画面。

切换图像前会自动保存。关闭页面前若仍有未保存修改，浏览器会给出提示。

## 坐标与文件

画布显示可缩放，但 JSON 中保存的是原图像素坐标，坐标原点位于图像左上角，`x` 向右、`y` 向下。每张图保存为：

```text
annotations/manual/<原图文件名（不含扩展名）>_manual.json
```

每条标注包含 `row_id`、`start: [x, y]` 和 `end: [x, y]`。其结构与算法输出中的有限线段端点兼容，可直接用于后续匹配、角度误差、端点误差、漏检和重复检测评估。

“算法参考”开关默认关闭。人工标注阶段建议保持关闭，避免已有预测结果造成认知诱导；完成独立标注后可打开作快速视觉核查。

## 浏览器实现说明

工具使用本地服务读取项目影像并由用户主动保存 JSON。浏览器不应在没有用户许可的情况下任意访问本地文件系统；Web 文件系统访问能力也具有安全上下文和兼容性约束 [1][2]。因此，本工具没有依赖实验性的目录写入接口，而是使用仅绑定 `127.0.0.1` 的本地服务完成明确目录内的标注读写。
