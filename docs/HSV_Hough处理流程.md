# HSV + Hough 棉花种植行方向识别处理流程

## 1. 目标与边界

输入为无人机 RGB 原始航片。输出包括：植被二值掩膜、每条可辨识种植行的一条橙色有限中心线段、每条线段两端的橙色端点，以及结构化 JSON 结果。

这里不把 Hough 检出的无限参数直线直接作为最终结果。Hough 只负责估计全图占优的种植行轴向；各行的横向位置由植被掩膜在法向上的投影峰值确定，端点由对应行走廊内真实植被支持范围确定。因此，一条种植行只生成一条中心线，不沿叶缘重复出线。

本方法是零训练基线，适用于行结构近似平行、RGB 中植被与土壤/地膜颜色可分的航片。它不等价于对所有生育期、阴影、杂草和强透视场景都稳健。经典 Hough 在棉花 UAV 影像上可取得较高检测率，但已有对比研究指出，复杂冠层下经典 Hough 会产生错误方向线，代表点拟合可能更准确 [1]。基于 UAV RGB 的行作物研究也指出，Hough 可跨越缺苗造成的断裂，但直接作用于稠密掩膜存在计算量和过检风险 [2]。

## 2. 处理流程

### 2.1 读取与尺度归一化

读取 JPEG/PNG/TIFF，保留原始像素尺寸。为控制 20–25 MP 航片的运算量，将长边缩放到可配置的工作尺寸（默认 1800 px）；最终线段坐标再映射回原图。所有固定像素阈值只在工作尺度上使用。

### 2.2 HSV 植被分割

将 BGR 转到 HSV。默认保留绿色范围 `H=25–100`、`S>=35`、`V>=25`。色相用于排除灰白地膜与黄褐土壤，饱和度用于抑制低彩度背景，亮度下限用于抑制深阴影噪声。阈值均可通过命令行调整。

随后执行：

1. 小尺度开运算，删除孤立彩色噪声；
2. 小尺度闭运算，连接同一叶片或相邻苗体的细小裂缝；
3. 连通域面积过滤，删除明显小于有效苗体的斑点。

输出的掩膜是“HSV 植被候选”，不是棉花/杂草语义分类结果。行间杂草仍可能进入掩膜，后续依赖平行性、周期行距和长程支持度抑制假行。

### 2.3 Hough 主方向估计

对清理后的掩膜做 Canny 边缘提取，并用概率 Hough 变换获得有限候选线段。Hough 直线的核心参数关系为 `rho = x*cos(theta) + y*sin(theta)`；共线像素在参数空间形成峰值 [3]。

候选线段先按长度过滤，再把角度归一到 `[0, 180)`。由于直线没有正反方向，采用二倍角圆统计计算占优轴向；之后只保留与占优方向差小于阈值的候选，按线段长度加权再次估计。若候选不足，任务明确失败，不用不可信默认角度伪造结果。

### 2.4 旋转、投影与行中心定位

把掩膜旋转，使主方向变为竖直方向。沿竖直方向求和，得到横向植被密度曲线。对曲线做高斯平滑后：

1. 用自相关估计占优像素行距；
2. 用最小峰间距约束寻找横向峰；
3. 用峰值显著性和全图最大响应比例剔除弱峰；
4. 每个峰只定义一个行走廊，避免同一冠层两侧各产生一条线。

物理行距固定并不意味着不同航片具有固定像素行距，因此像素行距必须逐图估计；这里不依赖缺失的飞行高度或 GSD。

### 2.5 每行有限中心线拟合

在每个峰对应的行走廊内收集掩膜像素。为防止大叶片按面积主导拟合，每个纵向小区间只取植被像素横坐标中位数，形成稀疏代表点。随后对代表点做稳健直线拟合，并限制其角度不得显著偏离 Hough 全局主方向。

端点取代表点沿行方向坐标的低、高分位数，而不是与图像边界求交。这样得到的是由实际植被证据支持的有限线段。线段长度、纵向覆盖率或点数不足时，该候选行被拒绝。

### 2.6 输出与质量信息

每张输入图输出：

- `*_mask.png`：0/255 HSV 植被掩膜；
- `*_rows.png`：原图叠加橙色中心线和两个圆形端点；
- `*_rows.json`：主方向、估计像素行距、掩膜占比、每条行的原图端点与置信特征；
- `run_summary.json`：批处理成功/失败汇总和实际参数。

## 3. 主要失败条件

- 冠层闭合导致相邻行在掩膜中连成整片；
- 杂草沿另一方向形成更强的周期结构；
- 地膜反射带有绿色偏色，进入 HSV 掩膜；
- 航片倾斜导致同图行距变化明显，单一全局投影不再成立；
- 多地块、多方向同时出现，而单一主方向模型只保留占优方向；
- 行端位于画面外时，输出端点是图内可见支持端点，不是田间物理行端。
